# Incident Scenario Overview

## Inspiration & Adaptation
This scenario is inspired by the well-known "Rhino Hunt" from NIST but has been adapted to suit the specific needs of our research.

## Scenario Description
- The scenario simulates a data exfiltration attack through an FTP server.
- The knowledge base represents log entries of exfiltrated images (instead of real exfiltrated data).

## Enhancing Context for Investigation
To provide more detailed context for the incident and investigation:
- Descriptions of the images have been added to the knowledge base for each event.
- A rule was created to select images for analysis based on specific hash values and other relevant metadata.

## Metadata Visualisation
- A metadata extractor module has been added to visualise the metadata of each image in the folder.

## AI-Generated Images
- The images used in this scenario are AI-generated with DALL·E.
- This allows for the modification of metadata without concerns about privacy or consent.
